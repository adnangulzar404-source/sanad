# Contributing

Before adding any source text, translation, Hadith, tafsir, or metadata:

1. Add the source to `data/sources.json`.
2. Record exact edition, version, license, and permitted uses.
3. Do not add content with unclear redistribution rights.
4. Add a checksum and a provenance note.
5. Have a qualified content reviewer check the relevant records.
6. Add a test for quotation integrity or abstention behavior.

Pull requests that add unlicensed or unattributed religious text should not be merged.
