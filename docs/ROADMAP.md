# Roadmap

## Phase 0 — current prototype

- Static verification interface
- Tiny demo corpus
- Test suite and evidence cards
- Source register

## Phase 1 — competition MVP

- Import full Tanzil text verbatim
- Add hybrid lexical + vector retrieval
- Add a permissioned Hadith subset
- Add claim-level citations
- Add specialist handoff packet
- Produce evaluation report

## Phase 2 — production pilot

- API service
- Human review dashboard
- Reviewer disagreement workflow
- Corpus versioning and rollback
- Audit logs
- Arabic/English localization
- Specialist directory and referral process

## Explicit non-goals

- Autonomous fatwa generation
- Silent correction of Qur’an or Hadith quotations
- Unlicensed scraping
- Training on real user conversations
