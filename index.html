What this file is — and is not

Shipped in this prototype

  • Quotation detection in Arabic and Latin punctuation
  • Canonical vs search-normalized Arabic matching
  • Exact / near / wrong-reference / fabricated classification
  • Claim-level warnings (unanimity, missing citations)
  • Retrieval-first Q&A over a closed corpus
  • Specialist handoff for personal rulings
  • Source and license cards
  • Runnable adversarial suite

Not shipped here

  • Full Tanzil import (download + checksum yourself)
  • A licensed Hadith edition
  • A hosted API or GitHub repository
  • A two-minute video or slide deck
  • A live large language model
  • Fatwa generation — by design

Architecture

User text → detect quoted spans and claims → normalize a search copy only → exact then near match against the store → classify → render citation cards. Generation, when present, may only write around retrieved spans. Qur’an and Hadith strings are copied, never invented.

Display policy: canonical_only. The stored Arabic is not silently repaired. Differences are shown.

Safety policy

Sanad answers established educational questions from the corpus. It does not issue personal fatwas, flatten disputed legal schools into one ruling, or treat a single report as a verdict. Inheritance, marriage, divorce, finance, worship obligations for a named person, and “is this haram for me” are handed off with a specialist packet.

Two-minute demo script

  1. 0:00 Problem — fluent AI is not evidence. Show the flawed sample.
  2. 0:15 Verify — green exact quote, red wrong reference, orange unanimity claim, grey missing citation.
  3. 0:40 Difference view — submitted Arabic vs stored Arabic. No silent rewrite.
  4. 1:00 Ask — “What does Al-Ikhlas teach?” Arabic source, demo gloss, citation card.
  5. 1:25 Abstain — “Give me a fatwa about my divorce.” Handoff summary.
  6. 1:45 Close — this is a verification layer, not another chatbot.
